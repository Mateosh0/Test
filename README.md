# BookShelf PWA

Особиста бібліотека українською: полиці, прогрес, оцінки, цитати, нотатки, статистика, пошук, JSON резервні копії.

## Публікація на GitHub Pages
1. Створіть публічний репозиторій на GitHub.
2. Завантажте **вміст** цієї папки у корінь репозиторію (index.html, sw.js, manifest.webmanifest, icons/).
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. Відкрийте адресу Pages на iPhone в Safari → Поділитися → На початковий екран → Додати.

Дані зберігаються в localStorage конкретного браузера/встановленого застосунку. Регулярно експортуйте резервні копії. Немає синхронізації між пристроями. Зовнішні обкладинки можуть не працювати офлайн. Важливо: якщо ви відкриваєте index.html локально як файл, service worker не активується; використовуйте HTTPS через GitHub Pages.
