# 7:15 Coffee — дизайн-концепт

Відкрийте `index.html` у браузері або завантажте файл на статичний хостинг (Netlify, GitHub Pages).

Це неофіційний дизайн-концепт. Фотографії завантажуються із Unsplash, потрібне інтернет-з'єднання. Меню є демонстраційним і не підтверджує наявності товарів чи цін. Для офіційного запуску необхідні дозвіл бренду, затверджене меню, адреси, фотографії та контакти.
