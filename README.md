# AURA Weather 2.0

Сучасний український PWA-додаток погоди для iPhone.

## Запуск
Завантажте **всі** файли з цієї папки на HTTPS-хостинг (наприклад, Netlify Drop або GitHub Pages). Відкрийте адресу у Safari → Поділитися → На початковий екран.

Для локального тестування можна запустити HTTP-сервер у папці проєкту. Самого відкриття `index.html` з файлового менеджера недостатньо для повної роботи PWA та геолокації.

## Дані
Прогноз: Open-Meteo Forecast API; пошук міст: Open-Meteo Geocoding API. Інтернет потрібен для актуальних даних. Початкове місто — Одеса. Місцеперебування запитується лише після натискання кнопки геолокації.

## Файли
`index.html`, `style.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`.
