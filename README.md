# AURA Weather — PWA

Україномовний погодний вебдодаток для iPhone. Працює з безкоштовним Open-Meteo API без ключа.

## Публікація

Завантажте **вміст** цієї папки до статичного HTTPS-хостингу (наприклад, Netlify Drop або GitHub Pages). Не відкривайте index.html як локальний файл: для PWA, геолокації та service worker потрібен HTTPS (або localhost).

## Встановлення на iPhone

Відкрийте опубліковану HTTPS-адресу в Safari → Поділитися → На початковий екран → Додати.

## Можливості

Поточна погода, погодинний прогноз, 10 днів, пошук міст, геолокація, динамічні теми, збереження міста. Інтернет потрібен для оновлення прогнозу. Для максимально сумісної іконки iOS згодом варто додати PNG 180×180.
