# McTime — облік змін працівників

Незалежний прототип для локального використання, неофіційний продукт McDonald's.

## Запуск
1. Встановіть Python 3.10+.
2. У терміналі в папці проєкту: `python -m pip install -r requirements.txt`
3. Задайте секрети (рекомендовано): `SECRET_KEY` — довгий випадковий рядок, `ADMIN_CREATE_CODE` — власний код реєстрації (за замовчуванням 1786 лише для демонстрації).
4. Запустіть: `python app.py`
5. Відкрийте http://127.0.0.1:5000

База SQLite створюється автоматично у `mctime.sqlite3`. Зберігайте її резервні копії. Час подій записується в UTC і відображається в часовому поясі сервера.

## Можливості
- Реєстрація адміністратора за кодом, генерація логіна і пароля, зберігання хешу пароля.
- Вхід адміністратора, прив'язка до номера ресторану.
- Додавання та деактивація працівників, унікальні панч-номери в межах ресторану.
- Початок/завершення зміни, початок/завершення перерви, перевірка дозволених переходів на сервері.
- Історія змін, журнал подій, експорт CSV.

## Важливо перед реальним використанням
Це MVP для одного локального комп'ютера, а не захищена корпоративна система. Для публічного доступу необхідні HTTPS, постійний SECRET_KEY, захист від CSRF, обмеження спроб входу/підбору панч-номерів, належна політика персональних даних, захищена реєстрація адміністраторів (код 1786 не повинен бути загальнодоступним), резервне копіювання, журнал адміністративних дій і серверна база даних для багатьох пристроїв. Панч-номер без додаткового підтвердження дозволяє відмітити час за іншу людину.
