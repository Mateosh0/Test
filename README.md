# CourierLog

Україномовний офлайн PWA для обліку доставок, чайових, витрат та робочих змін.

## Публікація на GitHub Pages
1. Створіть публічний репозиторій на GitHub.
2. Завантажте файли цього каталогу **в корінь репозиторію**.
3. Відкрийте **Settings → Pages → Build and deployment → Deploy from a branch**, оберіть `main` та `/ (root)`, натисніть Save.
4. Відкрийте адресу `https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/`.
5. На iPhone у Safari натисніть **Поділитися → На початковий екран → Додати**.

Усі дані зберігаються у `localStorage` браузера; резервні копії JSON можна експортувати в розділі «Опції». Очищення даних Safari може стерти записи. Немає синхронізації між пристроями.

Для кращої підтримки іконки iOS у майбутньому додайте PNG-іконки 180x180 та 192x192/512x512.
